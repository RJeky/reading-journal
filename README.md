# Читательский дневник

Личный трекер чтения в стиле рукописной тетради. На главной отображается текущая книга с обложкой и прогрессом. На полке можно искать книги и фильтровать их по статусу.

- Добавление вручную или поиск по названию, автору и ISBN через Open Library.
- Формат книги, жанр, заметки и собственные обложки.
- Прогресс по страницам, позициям в электронной книге или процентам.
- Записи о прочитанных страницах и времени чтения с итогами по годам.

## Локальный запуск

В корне репозитория запусти статический сервер:

```sh
python -m http.server 8000 --directory dist
```

Открой [http://localhost:8000](http://localhost:8000). Сборка и установка зависимостей не нужны.

Книги, обложки и записи о чтении сохраняются в браузере. Сетевой доступ нужен для поиска в Open Library и загрузки обложек из каталога. Платные API и API-ключи не используются.

Шрифт Caveat распространяется по [SIL Open Font License](dist/caveat-OFL.txt).
